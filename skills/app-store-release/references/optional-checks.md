# 보류 중인 선택 점검

현재 필수 체크리스트에 포함하지 않은 제안이다. 사용자가 선택하거나 구체적인 문제 해결에 필요한 항목만 범위에 추가한다. 필수 항목 수행에 필요한 좁은 검증까지 보류하는 뜻은 아니다.

| 항목 | 선택했을 때 확인할 내용 |
|---|---|
| 배포 전 주요 기능 테스트 | 로그인, 광고, 알림 등 앱의 핵심 흐름 |
| 기기·OS별 호환성 | 구형 기기, 최신 OS, 태블릿·폴더블의 동작 |
| 성능 | 시작 속도, 메모리·배터리 사용량, 앱 용량 |
| 접근성 | 글자 확대, 화면 읽기, 터치 영역 |
| 단계적 배포 | 일부 사용자에게 배포 후 확대 조건 |
| 배포 후 모니터링 | 크래시, ANR, 사용자 리뷰와 확인 기간 |
| 문제 발생 시 복구 계획 | 배포 중단, 수정 버전 제출과 복구 절차 |
| 서명 키·배포 산출물 백업 | 키, 최종 바이너리 등 복구 가능 여부 |

범용 적용 시 Android ANR·AAB 등 플랫폼 전용 항목은 해당 플랫폼으로 제한한다. 선택되지 않은 항목이 미실행이라는 이유만으로 필수 준비도를 실패 처리하지 않는다.
