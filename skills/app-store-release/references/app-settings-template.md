# 앱별 배포 설정 양식

프로젝트에 `docs/app-store-release-settings.md`로 두거나, 여러 앱의 공통 설정은 상위 작업공간의 동일 경로에 둔다. 실제 앱 점검 기록과 이 설정 원본을 구분한다. 사용자별 키 선택이나 계정 정보를 공개 스킬 원본에 고정하지 않는다.

## 공통 기본값

| 항목 | 값 |
|---|---|
| 지정 업로드 키의 안전한 식별 이름 | 프로젝트 운영 기준을 입력 |
| 배포 기록 위치 | 기존 문서 위치 또는 docs/releases/ |
| 보류 선택 점검 | 기본은 보류, 선택한 항목만 명시 |

## 앱별 설정

| 항목 | 값 |
|---|---|
| 앱 이름 / 플랫폼 / 앱 식별자 | |
| 로컬 프로젝트 / 저장소 URL(있는 경우) / 배포 브랜치 | |
| 스토어 Console 주소 / 공개 주소 | |
| 운영 환경 / Firebase 프로젝트 식별자 | |
| 홈페이지 / 앱·스토어의 개인정보 처리방침 URL | |
| 사용 업로드 키 식별 이름 / 공통값과 다른 이유 | |
| 앱 서명 인증서·업로드 인증서의 안전한 참조 | |
| 키 교체 가능 여부 / 확인일 / 처리 상태 | |
| 매핑·심볼 보관 및 업로드 결과 참조 위치 | |
| 앱별 예외 / 선택 점검 | |

키 파일·비밀번호·인증 토큰·인증서 개인키는 이 문서에 넣지 않는다. 미확인 값을 추측해 채우지 않는다.
